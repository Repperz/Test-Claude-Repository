# Get Ben to the Beers

A tap-to-jump pixel-art runner for mobile. Open `index.html` in any browser (it's a single file, no build step).

- **Tap** (or Space) to jump
- **Pints**: +1 score, but each one makes the screen wobble more and the controls get drunker (input lag, wobbly jumps, hiccups, double vision)
- **Kebabs**: sober you up a bit
- **Kebab queues**: jump over them, or lose a dignity (lose all 3 and you're thrown out)
- **Bouncers**: jump over them, or you're thrown out ("Not today, pal")
- **Texts from Mum or Helen**: fly in at head height, so *don't* jump into them. Mum's ends the night with a school-run pickup; Helen's puts Ben in the doghouse.
- Survive to 11pm and Ben makes it to the pub for last orders.
